# Definition of Done

A feature is done only when:

- contract remains valid;
- implementation is deterministic where required;
- all substantive generated claims are SIIS-grounded;
- deeplinks follow catalog/dummy-positive policy;
- tests cover the changed behavior;
- canonical and adversarial regression tests pass;
- unseen-SIIS behavior has not regressed;
- cache isolation is preserved;
- no secrets/generated dependencies are added;
- documentation reflects actual behavior.
